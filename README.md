# Istituto Caso – Video tour

Sito statico: `index.html` mostra il video e un pulsante per scaricarlo.

## Pubblicare su GitHub Pages
1. Crea un repository su GitHub e carica tutti questi file (cartella `video/` compresa).
2. Settings → Pages → Source: *Deploy from a branch* → branch `main`, cartella `/ (root)` → Save.
3. Dopo un minuto il sito è su `https://TUO-NOME.github.io/NOME-REPO/`.

Per cambiare video: sostituisci `video/istituto_caso_tour.mp4` mantenendo lo stesso nome.
