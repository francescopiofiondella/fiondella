Pannelli visita 3D – Istituto Caso

Per ogni lavagna o LIM puoi caricare un'immagine e, se vuoi, collegarla a un link. Quando premi Salva e pubblica le modifiche compaiono nella visita 3D (al prossimo caricamento della pagina, di solito entro un minuto). Lascia vuoto il link se vuoi solo mostrare l'immagine.

Impostazioni di pubblicazione

Le immagini e i link vengono salvati in un repository GitHub (gratuito) da cui la visita 3D li legge. Questi dati restano solo nel tuo browser.

Come creare il token
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Resource owner: il tuo account/organizzazione. Repository access: «Only select repositories» e scegli il repository.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Copia il token e incollalo qui sopra.
